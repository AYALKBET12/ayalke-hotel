# Ayalke International Hotel

A hotel information and food-delivery website built with React and Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

## Deploy to Render

The `render.yaml` Blueprint configures this project as a static site. In Render,
create a new Blueprint instance from the GitHub repository and Render will build
the site with `npm ci && npm run build` and publish the `dist` directory.
